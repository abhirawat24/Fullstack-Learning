Git commands - 
              i> clone- brings the repository hosted somewhere into folder or local machine
              ii> add - track your files and changes in git
              iii> commit - save your files in git
              iv> push - upload your commits to a git repo, like GitHub
              v> pull - download changes from a remote repo to local repo.


git commands to solve conflicts 
     i> git log --merge : produce the list of commits that are causing the conflits
     ii> git diff : identify the differences between the states repositories or files.
     iii> git checkout : used to undo changes made to the file, or for changing area.
     iv> git reset --mixed : used to undo changes to the working directory and staging area.
     v> git merge --abort : helps in exiting the merge process and returning back to the state before the merging began.
     vi> git reset : used at the time of merge conflit to reset the conflicted files to their original state.
