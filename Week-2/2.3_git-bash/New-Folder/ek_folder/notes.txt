**************************Permissions for files and folders*********************************
                          (-r -w -x symbols)

   i> chmod (change file Permissions " modify the read, write and execute Permissions of a file)(u "user" g "group" o "other", - removing a Permission, + giving a Permission , weather it be r "read", w "write", or x "execute" or rwx)(then specify the file you want to do it for)(if it is a folder you have to add a -R)
   For example - "chmod u+x index.js" would add an execute Permission to the index.js for the user
   *numaric 4 is for read , 2 is for write , 1 is for execute*
   ii> echo "message" (would display a message to the terminal)
       echo $PATH (would display the path that your current location is in a detailed version)
   iii> head file.txt (would give you the top 10 rows of the file.txt)
   iv> tail file.txt (would give you the last 10 lines of the file.txt)
   v> head -20 file.txt (would give you the top 20 lines of the file.txt) tail -20 file.txt (would give the last 20 lines of file.txt)
   vi> command 1 | command 2 (a pipe operator whatever command comes from command 1 flows to command 2)
       example - tail -n +25 newfile.txt | head 5
   vii> wc (command gives a number of lines, number or worlds and number of characters)
   viii> grep "one" newfile.txt (this command would give you the number of occurence of a word, phrase or line in the example we looking for the occurence of one in newfile.txt)
         grep "one" newfile.txt | wc (giving word cound of one in file.txt)
         grep "one" newfile.txt | wc -l (gives number of times it was used)
         grep -c "one" newfile.txt (print the number of count of lines it occured)
         grep -h "one" newfile.txt (give you the times when it occured)
         grep -hi "one" newfile.txt (would give you even the updates or the occurance within another word)
         grep -hir "one" . (this will do it for the whole directory even recursively)
         grep -hin "one" newfile.txt (would give the exact line number where the "one" is written)
         grep -o "one" newfile.txt (will only give you the matched parts)
   ix> history 0 (this command is used to view all the commands you have used in the terminal)      

        grep -A 5 ERROR log.txt (will give you the 5 lines after the occurence of that)
        grep -B 5 ERROR log.txt (will give you the 5 lines before the occurance of that)
        grep -C 5 ERROR log.txt (will give you the 5 lines before and 5 lines after the occurance of that)
