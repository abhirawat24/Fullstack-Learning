Defining Schema :-
example:- 

const UserSchema = new mongoose.Schema({
   email: String,
   password: String,
   purchasedCourse: [{
      type: mongoose.Schema.Type.ObjectId,
      ref: 'Course'
      }]
});

const CourseSchema = new mongoose.Schema({
   title: String,
   price: 5999
});


calling the schema :-

const User = mongoose.model('User', UserSchema);
const Course = mongoose.model('Course', CourseSchema);

SQL databases does not let you store complex objects or data and follows a strict schema while using mongoDB we store complex objects in form of tables and we can define relationships between the data that is what the benifit we have in NoSQL database like MongoDB where we can give "refrences" to another table.
