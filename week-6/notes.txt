>>>>Re-Rendering in React

A re-render means that

1. React did some work to calculate what all should update in this Component
2. The component actually got called
3. The inspector shows you a boundering box around the component

It happens when

1. A state variable that is being used inside a component changes
2. A parent component re-render triggers all children re-Rendering

 You want to minimise the number of re-renders to make a highly optimal react application
 The more the components that are getting re-rendered, the worse. if a parent state changes all the children re-render
 Pushing to the lowest ansestor is a good practice as the number of re-renders decreases.
 
  *The rule of thumb* - If there are multiple children in a tree or multiple component that need to use a state variable, you need to find the lowest common ansestor and store it there. or structure it in such a way that you push it down to the owest ansestor possible to avoide the unwanted re-renders.

The "useEffect" hook serves the same purpose as 'componentDidMount', componentDidUpdate', and 'componentWillUnmount' in React class components, but unified into a single API.
